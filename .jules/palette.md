## 2024-05-30 - Interactive Elements Keyboard Shortcut Avoidance
**Learning:** When implementing global keyboard shortcuts (like "r" for reload) attached to `document.addEventListener("keydown")`, naive checks for active tags like `INPUT`, `SELECT`, and `TEXTAREA` are insufficient. Interactive controls like `BUTTON`s, or custom UI elements utilizing ARIA roles like `role="tab"` or `role="radio"` also need explicit focus state exclusion to prevent users from accidentally triggering the global shortcut while actively interacting with or navigating those controls via keyboard (e.g. using arrow keys or enter).
**Action:** Ensure all `keydown` global listener guard clauses explicitly check for active `BUTTON` tags and custom interactive roles (`tab`, `radio`) via `getAttribute("role")`.
