## 2025-05-26 - Keyboard shortcut hints and robust event listeners
**Learning:** When adding global keyboard shortcuts to a web UI, it is critical to guard the `keydown` event listener not just against input fields (`INPUT`, `SELECT`, `TEXTAREA`), but also against native interactive elements like `BUTTON` or elements with specific accessibility roles (`role="tab"`, `role="radio"`). Failure to do so can break standard keyboard navigation (like using arrow keys to switch tabs).
**Action:** Always include a comprehensive check of `document.activeElement.tagName` and `document.activeElement.getAttribute('role')` before executing custom logic in global `keydown` handlers. Also, tooltips (`title` attribute) are an effective way to dynamically explain why a button is disabled to improve accessibility.
